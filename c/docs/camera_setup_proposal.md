# 카메라 설치 조건 제안서

**수신**: 카메라 설치 담당 엔지니어님
**발신**: 비전 AI 파이프라인 개발팀
**목적**: 무인매장 트래킹 시스템이 정상 동작하기 위해 카메라 설치 시 반드시
확보되어야 하는 **시야각·화질·환경 조건**을 체크리스트로 제안드립니다.
설치 후 아래 검증 절차까지 함께 진행 부탁드립니다.

> 배경: 본 시스템은 영상에서 사람을 추적해 "입장 → 키오스크(결제) → 착석 → 퇴장"
> 동선을 기록하고, 미결제 체류·쓰러짐 등의 상황을 점주에게 알립니다.
> 판정 기준점이 **사람의 발밑 위치**와 **결제기 앞 행동**이기 때문에,
> 아래 항목이 화각에서 빠지면 해당 기능이 통째로 동작하지 않습니다.

---

## 1. 시야각(FOV) 필수 체크리스트

우선순위 순입니다. 카메라 1대로 전부 커버가 안 되면 **위에서부터** 확보하고,
나머지는 카메라 추가를 제안드립니다.

- [ ] **① 결제기기(키오스크/POS) 전면과 조작하는 손이 보인다**
  - 결제 행동과 영상의 크로스체크 근거. "결제 없이 착석" 판정의 기준점입니다.
  - 화면에서 결제기가 가구·기둥에 일부라도 가리면 안 됩니다.
- [ ] **② 바코드 리더기와 상품을 가져가는 손의 동선이 보인다**
  - 토스 단말기 등 외부 결제기 매장에서 결제-행동 매칭이 꼬이는 것을 방지합니다.
- [ ] **③ 출입문 전체가 바닥까지 보인다**
  - 입장/퇴장 판정 시작점. 동선 기록("14:00 입장 → …")의 신뢰도가 여기서 결정됩니다.
  - 문 상단만 보이고 바닥이 잘리면 입장 감지가 늦습니다.
- [ ] **④ 테이블·좌석 구역의 "발밑"이 보인다**
  - 구역 판정은 발밑 좌표 기준입니다. 테이블 상판이 앉은 사람의 발밑을 가리는
    각도는 피해주세요 (체류/미구매 착석 판정 불가).
- [ ] **⑤ 비품대(시럽·빨대·컵홀더)와 진열대가 보인다**
  - 비품 어뷰징 감지·진열 관리 기능의 전제 조건 (우선순위 낮음 — 여유 있을 때).

## 2. 설치 높이·각도 체크리스트

### 전역 카메라 (천장/벽 부착)

- [ ] 높이 **2.4~3.0m**, 부감 **20~40°**
- [ ] 통로 축과 나란히 보도록 설치 (사람끼리 겹침 최소화)
- [ ] 앉은 손님의 발밑이 테이블에 가리지 않는 각도

### 키오스크 근접 카메라 (키오스크 부착)

- [ ] 키오스크 화면 상단, 사용자 얼굴 정면 기준 **±15°**
- [ ] 성인이 조작 위치에 섰을 때 **얼굴 폭이 화면 가로의 13% 이상**으로 잡히는
  거리(대략 1m 이내) — 근접 판정이 이 비율 기준입니다.
  - 설치 후 디버그 창의 `face0.xx` 라벨로 실측값을 바로 확인할 수 있습니다.

## 3. 화질·조명 체크리스트

- [ ] 해상도 **최소 1280×720**, **15fps 이상** (고fps보다 화질·조도 안정이 중요)
- [ ] RTSP 카메라는 **H.264 baseline** 권장 (엣지 디코딩 부담 최소화)
- [ ] **역광 금지**: 출입문·창을 정면으로 보는 각도는 인물이 실루엣이 되어
  검출률이 급락합니다. 문을 봐야 하면 문 옆 벽면에서 비스듬히.
- [ ] **직사광 금지**: 렌즈에 해가 들면 백화현상으로 감지가 무력화됩니다.
  (시스템이 백화를 자가 진단해 알리지만, 애초에 각도로 피하는 것이 우선)
- [ ] 야간 상시 감시가 필요한 매장이면 **최소 조도(보조등) 유지 또는 IR 카메라**
  — 완전 암전이면 "영상 신호 이상"으로 분류됩니다.

## 4. 네트워크·전원 체크리스트

- [ ] RTSP 지연 **2초 이내** (지연이 크면 실시간 알림 의미가 없습니다)
- [ ] **PoE 권장**
- [ ] 전원 리셋 시 **자동 재스트리밍**되는 모델
  (파이프라인은 수신 실패 30회 연속 시 자동 재연결을 시도합니다)

## 5. 설치 후 현장 검증 절차 (같이 확인 부탁드립니다)

파이프라인을 켠 상태(`build/kiosk_tracking rtsp://...`)에서:

- [ ] 출입문으로 들어오는 사람이 **입구에서부터** 박스로 잡히는가
- [ ] 결제기 조작 위치에 서면 `[kiosk_enter]` 라벨이 뜨는가 (face 비율 ≥ 0.13)
- [ ] 좌석에 앉았을 때 발밑이 테이블 구역 안에 들어오는가
  (구역 자체는 점주 페이지에서 드래그로 조정 가능하니 대략만 맞으면 됩니다)
- [ ] 결제기 앞에서 상품 스캔 동작을 했을 때 손·리더기가 모두 화면에 보이는가
- [ ] 점주 페이지(`http://<엣지IP>:8765`)의 실시간 인원 오버레이가 실제 위치와
  일치하는가
- [ ] 렌즈를 손으로 잠깐 가렸을 때 "카메라 이상" 알림이 오는가 (자가 진단 확인)

## 6. 요약 — 꼭 지켜주셔야 하는 3가지

1. **결제기와 조작하는 손**이 반드시 화각에 들어와야 합니다.
2. **테이블 좌석의 발밑**이 보여야 합니다 (상판에 가리면 안 됨).
3. **역광·직사광**을 피한 각도여야 합니다.

세부 근거·기술 배경은 [카메라 설치 가이드라인](camera_install_guide.md)에 있습니다.
설치 환경상 위 조건 충족이 어려운 항목이 있으면 사전에 공유 부탁드립니다 —
카메라 추가 또는 판정 기준 조정으로 대응하겠습니다.
