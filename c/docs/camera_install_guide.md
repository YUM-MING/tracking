# 카메라 설치 가이드라인 (하드웨어 엔지니어용)

> 8/18 회의 결정사항: "카메라 화각 안에 바코드 리더기와 상품을 가져가는 손의 동선이
> 무조건 보여야 한다"는 필수 조건을 엔지니어에게 역제안한다.
> 이 문서는 비전 AI 파이프라인이 정상 동작하기 위한 **물리적 설치 조건**을 정의한다.

## 1. 화각(FOV)에 반드시 포함되어야 하는 것

우선순위 순서. 하나의 카메라로 전부 커버가 안 되면 **위에서부터** 지키고,
나머지는 카메라를 추가한다.

| 순위 | 대상 | 이유 |
|---|---|---|
| 1 | **키오스크/결제기 전면 + 조작하는 손** | 결제 내역(POS)과 영상의 크로스체크 근거. 결제 없는 착석 판정의 기준점 |
| 2 | **바코드 리더기와 상품을 가져가는 손의 동선** | 토스 단말기 등 외부 결제기를 쓰는 매장에서 결제-행동 매칭이 꼬이는 것을 방지 |
| 3 | **출입문 전체 (바닥까지)** | 입장/퇴장 판정 시작점. 동선 로그("14:00 입장 →…")의 신뢰도가 여기서 결정됨 |
| 4 | **테이블 좌석 구역** | 체류 시간/미구매 착석 판정. 좌석의 발밑이 보여야 함 (구역 판정은 발밑 기준) |
| 5 | **비품대(시럽·빨대·컵홀더), 진열대** | 비품 어뷰징·진열 증감 감지(로드맵 기능)의 전제 조건 |

## 2. 설치 높이·각도

- **천장/벽 부착(전역 카메라)**: 높이 2.4~3.0m, 부감 20~40°.
  - 사람이 서로 겹치지 않게 통로 축과 나란히 보도록 설치.
  - 발밑이 가려지면 구역(테이블/입구) 판정이 무너진다 — 테이블 상판이 좌석 발밑을
    가리는 각도는 피할 것.
- **키오스크 부착(근접 카메라)**: 화면 상단, 사용자 얼굴 정면 기준 ±15°.
  - 근접 판정은 "얼굴 폭 / 화면 가로 ≥ 13%" 비율 기준이므로, 성인이 조작 위치에
    섰을 때 얼굴 폭이 화면 가로의 13% 이상으로 잡히는 거리(대략 1m 이내)여야 한다.
  - 설치 후 점주 페이지의 face 비율 표시(디버그 창 라벨)로 실측 확인 가능.

## 3. 해상도·프레임

- 최소 1280×720 / 15fps. 파이프라인은 프레임을 샘플링(기본 5프레임당 1회 추론)
  하므로 고fps보다 **화질과 조도 안정**이 중요하다.
- RTSP 카메라는 H.264 baseline 권장 (엣지 디코딩 부담 최소화).

## 4. 조명·역광 조건

- 출입문·창가를 정면으로 보는 각도는 **역광으로 인물 실루엣화** → 검출률 급락.
  카메라가 문을 볼 때는 문 옆 벽면에서 비스듬히 보도록.
- 야간 소등 시 완전 암전이면 파이프라인이 "영상 신호 이상(가림/소등)"으로
  분류한다. 상시 감시가 필요하면 최소 조도(보조등) 유지 또는 IR 카메라 사용.
- 직사광이 렌즈에 들면 백화현상으로 감지가 무력화된다. 시스템이 백화를 자가 진단해
  점주에게 알리지만(camhealth), **애초에 렌즈에 직사광이 들지 않는 각도**로 설치할 것.

## 5. 네트워크·전원

- RTSP 지연 2초 이내 (지연이 크면 실시간 알림 의미가 없다).
- PoE 권장. 전원 리셋 시 자동 재스트리밍되는 모델일 것 —
  파이프라인은 수신 실패 30회 연속이면 자동 재연결을 시도한다.

## 6. 설치 후 검증 절차 (엔지니어 체크리스트)

1. `build/kiosk_tracking rtsp://...` 실행, 디버그 창에서 확인:
   - [ ] 출입문에서 들어오는 사람이 입구에서부터 BBox로 잡히는가
   - [ ] 키오스크 조작 위치에서 `[kiosk_enter]` 라벨이 뜨는가 (face 비율 ≥ 0.13)
   - [ ] 좌석에 앉았을 때 발밑이 테이블 구역 안에 있는가 (구역은 점주 페이지에서 드래그 조정)
2. 점주 페이지(`http://<엣지IP>:8765`)에서:
   - [ ] 실시간 인원 오버레이가 실제 위치와 일치하는가
   - [ ] 렌즈를 손으로 가려 "카메라 이상" 알림이 오는가 (자가 진단 동작 확인)
3. 결제기 앞에서 상품 스캔 동작을 하며 손·리더기가 모두 화면에 보이는지 녹화로 확인.
