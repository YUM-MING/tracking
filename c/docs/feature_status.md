## 최적화 (8/7·8/9)

| 항목 | 상태 | 비고 |
|---|---|---|
| 생산자-소비자 스레드 분리 | ✅ | 캡처↔추론, lock-free 트리플 버퍼 (`framebus.c`) |
| Lock-Free 링 버퍼 | ✅ | 뮤텍스 0개, C11 `atomic_exchange` |
| Zero-Copy | ✅ | 크롭 = 프레임 포인터+사각형, 캡처→버퍼 복사 1회만 |
| 정적 할당 / 루프 내 malloc 0회 | ✅ | 전 모듈 고정 배열, 초기화 시 1회 할당 |
| 6스레드 역할 분배 | ✅ | 캡처/추론/이벤트/WS/점주HTTP/모니터 |
| Thread Affinity (코어 고정) | 🟡 | macOS 미지원 → QoS 클래스로 대체. 4200U(리눅스) 이식 시 `pthread_setaffinity_np` 교체 지점 주석 완료 |
| CPU 1/4 감축 KPI | ✅ | sys 기준 10~14% (모니터 상시 계측), 절전/영업시간 모드로 추가 감축 |
| DB 비동기 저장 스레드 | ❌ | 엣지 로컬 DB 요구사항 미확정 — 이벤트는 현재 WS로 서버 전송 (서버 측 DB) |

| 출입문 열림 감지 | ❌ | 문 상태 판별용 구역+엣지 검출 또는 도어 센서 연동 필요 |
| 진열대 증감 파악 (편의점 확장) | ❌ | 진열 구역 차분 분석 — 별도 과제 |
| 폭력 의심 | ✅ | 제로샷 관절 벡터 (2인 근접 + 고속 스윙 스트릭) — behavior.c |

| 낙상 (급강하 빠른 경로) | ✅ | 수직 속도 + 자세 붕괴 — 기존 자세 룰의 보조 경로 |
