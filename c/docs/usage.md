# 사용법 안내 (Usage Guide)

무인매장 키오스크 트래킹 파이프라인 — 실행·설정·점주 페이지·로그 열람 방법과,
각 기능을 수정할 때 봐야 하는 코드 위치를 한 문서로 정리한다.
빌드 방법·아키텍처는 [README.md](../README.md) 참고.

---

## 1. 카메라 설정법

### 로컬 웹캠으로 켜기 (개발/데모)

```bash
build/kiosk_tracking          # 인자 없으면 기본 웹캠(장치 0)
build/kiosk_tracking 1        # 웹캠이 여러 대면 장치 번호 지정
```

- macOS 최초 실행 시 **카메라 권한 팝업**이 뜬다 — 허용해야 영상이 들어온다.
  (팝업을 놓쳤으면: 시스템 설정 → 개인정보 보호 및 보안 → 카메라 → 터미널 허용)
- 종료는 영상 창 또는 터미널에서 `q`.

### IP 카메라 (매장 운영)

```bash
build/kiosk_tracking rtsp://아이디:비밀번호@192.168.0.xx:554/stream1
```

### 영상 파일 (오프라인 테스트)

```bash
build/kiosk_tracking video.mp4    # 파일 끝나면 자동 종료 (EOF)
```

### 해상도·추론 주기 바꾸기

기본 1280×720, 5프레임당 1회 추론. 기본값은 `src/config.h`의 `CFG_DEFAULT`
(`frame_width`, `frame_height`, `detect_every_n`)에서 바꾼다.
분석 주기·검출 신뢰도는 점주 페이지 슬라이더로도 런타임 조정 가능 (재빌드 불필요).

**수정하려면 볼 코드**
| 무엇을 | 어디를 |
|---|---|
| 카메라 열기/읽기/재연결 | `src/main.c`의 `capture_main()` (캡처 스레드) |
| OpenCV 캡처 래퍼 (장치/RTSP/파일 분기) | `src/cv_shim.cpp`, `src/cv_shim.h` |
| 해상도·샘플링 등 기본값 | `src/config.h` `CFG_DEFAULT` |
| 카메라 자가 진단 (프리즈/백화/블랙아웃) | `src/camhealth.c` |

## 2. 실행 플래그 정리

```bash
build/kiosk_tracking [소스] [플래그...]
```

| 플래그 | 의미 | 기본값 |
|---|---|---|
| `--no-window` | 디버그 창 없이 헤드리스 실행 (운영 배포) | 창 표시 |
| `--admin-port=8765` | 점주 페이지 포트 (`0` = 끔) | 8765 |
| `--ws=ws://호스트:포트/경로` | 이벤트를 외부 서버로 WebSocket 전송 | 끔 (로컬만) |
| `--log=pipeline.log` | 통합 로그를 파일에도 기록 | stderr만 |
| `--data-dir=data` | 파일럿 데이터 JSONL 축적 폴더 (`--data-dir=` 빈 값 = 끔) | `data/` |
| `--privacy` | 비식별 표시 — 영상을 열화상풍으로 뭉개고 박스/뼈대만 또렷이 (현장 데모용) | 끔 |

플래그 파싱은 `src/main.c`의 `main()` 앞부분에 있다 — 플래그를 추가하려면 여기.

## 3. 점주 페이지 보는 법

1. 파이프라인 실행 (기본으로 켜져 있음)
2. 브라우저에서 접속:
   - 같은 컴퓨터: `http://localhost:8765`
   - 매장 LAN의 다른 기기(점주 폰/태블릿): `http://<엣지 컴퓨터 IP>:8765`
3. **주의: 인증이 없다.** 매장 내부 LAN 전용 — 공유기 포트포워딩 등으로 외부에
   노출하지 말 것.

### 화면 구성

| 영역 | 기능 |
|---|---|
| 매장 상태 | 현재 인원, 추론 FPS, CPU/RSS, 카메라 진단 상태, 운영 모드(정상/절전/영업시간외/캘리브레이션) |
| 룰 체크박스 | 알림 룰 21종 ON/OFF — 시스템이 강제하지 않고 점주가 매장 정책대로 선택 |
| 민감도 슬라이더 | 체류 기준, 쿨다운, 쓰러짐 종횡비, 키오스크 근접 비율, 검출 신뢰도, 분석 주기 등 20종 |
| 구역·인식 범위 | 캔버스 드래그로 테이블/키오스크/비품 구역 지정, 인식 제외 셀 칠하기, 실시간 인원 오버레이 |
| 자동 세팅 | [세팅 시작하기] → 빈 매장 N분 가동 → 오탐 위치(거울·포스터·TV) 자동 마스킹 |
| 실시간 알림 | 이벤트 + 동선 증거("14:00 입장 → 14:02 키오스크 → …"). [오탐 신고] 누르면 해당 룰 임계값 자동 완화 |
| 최근 로그 | 파이프라인 로그 최근 128줄 열람 |

설정은 실행 폴더의 `store_settings.json`에 저장되어 재시작 후에도 유지된다.

### HTTP API (외부 연동용)

| 메서드 경로 | 용도 |
|---|---|
| `GET /api/status` | 상태 요약 (인원/FPS/CPU/모드) |
| `GET /api/settings` · `POST /api/settings` | 설정 조회/변경 |
| `GET /api/events?since=N` | 최근 이벤트 (증분 폴링) |
| `GET /api/live` | 실시간 인원 좌표 (오버레이용) |
| `GET /api/logs` | 최근 로그 128줄 |
| `GET /api/fpstats` | 룰별 알림/오탐 집계 |
| `POST /api/purchase {"track_id":N,"items":M}` | POS 결제 웹훅 — 미구매 판정 해제 |
| `POST /api/calibrate` | 자동 세팅 시작/중지/마스크 해제 |
| `POST /api/feedback` | 오탐 신고 (임계값 자동 완화) |

**수정하려면 볼 코드**
| 무엇을 | 어디를 |
|---|---|
| API 엔드포인트 추가/변경 | `src/admin_server.c` (`handle_request()` 안 경로 분기) |
| 화면(HTML/JS/CSS) | `web/owner_page.html` — 실행 파일 옆에서 매 요청 읽으므로 **재빌드 없이 수정 즉시 반영** |
| 설정 항목 추가·저장 | `src/store_settings.c`, `src/store_settings.h` |
| 점주 페이지 포트 기본값 | `src/config.h` `admin_port` |

## 4. 로그 보는 법

로그는 세 곳에서 볼 수 있다 (모두 동일한 통합 로거를 거친다):

1. **터미널 (stderr)** — 실행하면 바로 나온다. `[HH:MM:SS][레벨][태그] 메시지` 형식.
2. **파일** — `--log=pipeline.log`로 실행하면 파일에도 기록.
   파일 로그에는 날짜 포함(`[2026-08-31 14:00:00]…`) — 여러 날 파일럿 구분 가능.
   ```bash
   tail -f pipeline.log            # 실시간 보기
   grep '\[이벤트\]' pipeline.log   # 알림만 추출
   grep '\[동선\]' pipeline.log     # 퇴장 손님 동선만 추출
   ```
3. **점주 페이지** — 최근 128줄 (`/api/logs`).

상세(디버그) 로그는 점주 페이지의 "상세 로그" 체크박스로 켠다 — 판정 하나하나의
근거가 전부 기록된다 (`판정`, `캘리브` 태그).

### 분석용 데이터 (로그와 별개)

`data/` 폴더에 기계용 JSONL이 날짜별로 쌓인다 — pandas로 바로 분석 가능.
포맷과 분석 예제는 [README의 "파일럿 데이터 축적" 절](../README.md) 참고.

| 파일 | 내용 |
|---|---|
| `data/tracking.db` | **SQLite 원본 DB** — 파일 하나 복사로 전체 인계 (`sqlite3`/pandas로 바로 조회) |
| `data/events_YYYY-MM-DD.jsonl` | 알림 이벤트 1건 = 1줄 (병행 기록) |
| `data/journeys_YYYY-MM-DD.jsonl` | 퇴장 손님 1명 = 1줄 (입장/퇴장 시각, 체류, 키오스크·착석·결제 여부, 단계별 동선) |

**수정하려면 볼 코드**
| 무엇을 | 어디를 |
|---|---|
| 로그 형식·레벨·링버퍼 | `src/logger.c`, `src/logger.h` |
| JSONL 축적 (파일 회전·포맷) | `src/datastore.c`, `src/datastore.h` |
| 여정 레코드 내용 (steps 등) | `src/journey.c`의 `journey_store_record()` |
| 이벤트 레코드가 쓰이는 지점 | `src/main.c`의 `event_worker_main()` |

## 5. 가능한 것 목록 (기능 카탈로그)

### 알림 룰 (전부 점주 페이지에서 ON/OFF)

| # | 기능 | 판정 방식 | 기본 |
|---|---|---|---|
| 1 | 장기 체류 미구매 안내방송 | 테이블 300초+ 체류 & 결제 기록 없음 | 켬 |
| 2 | 쓰러짐 긴급 알림 | BBox 종횡비 + 연속 확정 프레임 | 켬 |
| 3 | 키오스크 앞 도움 요청 | 키오스크 앞 손 들어올림 제스처 | 켬 |
| 4 | 키오스크 미방문 착석 | 동선 기록에 키오스크 없이 착석 | 켬 |
| 5 | 카메라 하드웨어 이상 | 프리즈/백화/블랙아웃/초점 자가 진단 | 켬 |
| 6 | 구매 후 초과 체류 | POS 잔수 × 허용 시간(기본 1잔 1.5h) 초과 | 끔 (POS 연동 필요) |
| 7 | 반려동물 감지 | COCO 확장 모델 (`yolo11n.onnx`) | 켬 |
| 8 | 노키즈존 미성년 의심 | 얼굴 나이 추정 누적 투표 (`genderage.onnx`) | 끔 (매장 정책) |
| 9 | 외부 음식 반입 의심 | COCO 음식류가 테이블 구역에 놓임 | 끔 |
| 10 | 비품 어뷰징 | 비품 구역 N회 반복 방문 | 끔 (구역 지정 후) |
| 11 | 일행 수 대비 주문 부족 | POS 잔수 vs 감지 인원 대조 | 끔 (POS 연동 필요) |
| 12 | 폭력 의심 | 제로샷 관절 벡터 (2인 근접 + 고속 스윙) | 켬 |
| 13 | 기물 파손 의심 | 제로샷 관절 벡터 (단독 고속 스윙 반복) | 켬 |
| 14 | 장시간 배회 | 착석/구매 없이 10분+ 이동 | 켬 |
| 15 | 키오스크 무단·장시간 조작 | 연속 점유 5분+ | 켬 |
| 16 | 스마트 청소 알림 | 퇴석 후 테이블 잔여물(컵/그릇) 검출 | 끔 |
| 17 | 키오스크 동적 추천 컨텍스트 | 동행 수 + 시간대 → 키오스크 SW 전달 | 끔 (연동 필요) |

### 시스템 기능

- **동선 기록 (설명 가능한 로깅)** — 모든 알림에 "14:00 입장 → 14:02 키오스크 → …" 증거 첨부
- **재식별 (ReID)** — 옷 색·신체 비율 시그니처로 트랙 ID 안정화 (60초 갤러리)
- **자동 캘리브레이션** — 빈 매장 세션으로 오탐 위치 자동 마스킹
- **오탐 피드백 폐루프** — 오탐 신고 → 임계값 자동 보수화, 목표 오탐율(기본 5%) 관리
- **절전/영업시간 모드** — 무인 시 추론 4배 감속, 영업시간 외 캡처 저속 (발열 보호)
- **파일럿 데이터 축적** — 이벤트/여정 JSONL 자동 저장 (사후 분석)
- **서버 전송** — WebSocket으로 이벤트 실시간 전송 (재연결 백오프)
- **하트비트** — 1분마다 생존 신호 전송, 수신 모니터(`tools/heartbeat_monitor.py`)가 결손 시 알림
- **자동 재시작** — `tools/run_forever.sh` 워치독 (크래시 시 재기동 + 이력 기록)
- **비식별 표시** — `--privacy` 열화상풍 화면 (프라이버시/현장 데모)
- **POS 웹훅** — 결제와 영상 판정 크로스체크

## 6. 수정 가이드 — 전체 코드 지도

| 영역 | 파일 | 역할 |
|---|---|---|
| 진입점·스레드 오케스트레이션 | `src/main.c` | 캡처/추론/이벤트 워커 기동, 메인 루프 |
| 전역 설정·기본값 | `src/config.h` | 모든 임계값·룰 기본값 (`CFG_DEFAULT`) |
| 사람 검출·포즈 | `src/yolo_pose.c` | YOLO11n-pose ONNX 추론 |
| 추적 (ID 부여) | `src/tracker.c` | ByteTrack식 IoU 매칭 |
| 재식별 | `src/reid.c` | 색·비율 시그니처 |
| 트리거 선별 (2단계) | `src/roi_router.c` | 키오스크 근접/테이블 체류/쓰러짐 후보 |
| 정밀 분석 (3단계) | `src/analyzer.c` | 크롭 고해상도 재추론 |
| 판정 룰·이벤트 (4단계) | `src/fsm.c` | 상태 머신 — **알림 조건을 바꾸려면 대부분 여기** |
| 이상행동 (제로샷) | `src/behavior.c` | 폭력/파손/배회/무단조작 |
| 확장 객체 (동물/음식) | `src/objdet.c` | COCO 모델 |
| 나이 추정 | `src/age_est.c` | 노키즈존 |
| 동선 기록 | `src/journey.c` | 입장→키오스크→착석→퇴장 + 여정 JSONL |
| 이벤트 큐 | `src/fsm.c` (`evq_*`) | 스레드 세이프 큐 |
| 점주 페이지 서버 | `src/admin_server.c` | HTTP API |
| 점주 페이지 화면 | `web/owner_page.html` | 재빌드 없이 수정 가능 |
| 설정 영속화 | `src/store_settings.c` | `store_settings.json` 읽기/쓰기 |
| 통합 로그 | `src/logger.c` | stderr/파일/링버퍼 |
| 데이터 축적 | `src/datastore.c` | 이벤트/여정 JSONL |
| 서버 전송 | `src/ws_sender.c` | WebSocket 클라이언트 |
| 카메라 캡처 래퍼 | `src/cv_shim.cpp` | 유일한 C++ 파일 (OpenCV 격리) |
| 카메라 진단 | `src/camhealth.c` | 프리즈/백화/블랙아웃 |
| 프레임 버스 | `src/framebus.c` | lock-free 트리플 버퍼 |
| 리소스 계측 | `src/resource.c`, `src/profiler.c` | CPU/RSS, 단계별 추론 시간 |

빌드 대상 구성은 `CMakeLists.txt` — 새 `.c` 파일을 추가하면 `CORE_SOURCES`에 등록.
