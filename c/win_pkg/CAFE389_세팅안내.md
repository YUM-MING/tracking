# 카페389 노량진점 파일럿 — 사전 캘리브레이션 안내

이 패키지는 **카페389 노량진점 환경에 맞춰 설정이 미리 조정된 배포판**입니다
(매장 조사: 24시간 무인 · 5.5~6.5평 · 좌석 6개(1인×4/바/3인) · 메일빈 자판기형
머신 · 유리 칸막이/간접조명 인테리어).

## 미리 맞춰둔 것 (store_settings.json 동봉)

| 항목 | 값 | 근거 |
|---|---|---|
| 결제당 허용 체류 | **2시간** | 지시사항 "1잔에 2시간 정도는 괜찮다" |
| 체류 안내방송 기준 | 2시간 (룰은 꺼둠) | 스터디형 장시간 이용 문화 — 켜게 되면 이 기준 사용 |
| 영업시간 제한 | 없음 (24시간) | 389 = 365일+24시간. 심야에도 안전 감시 유지, 무인 시 절전이 발열 담당 |
| 미방문 착석·안내방송 룰 | **끔** | 자판기 매장이라 결제 크로스체크 불가 — 사내 테스트 오탐 1·2위 룰 |
| 켜진 룰 | 쓰러짐·폭력·파손·배회·무단조작·하드웨어·반려동물·도움요청 | 무인매장 안전·자산 보호 핵심만 |
| 작업 중 배려 | 켬 | 공부·노트북 손님을 체류 판정에서 제외 (노량진 수험생 상권) |
| 배회 기준 | 30분 | 6평 매장에서 착석 없이 30분 서성임은 이례적 |
| 자판기 점유 의심 | 10분 | 음료 자동 제조 대기 시간 고려해 여유 있게 |
| 행동 민감도 | 0.8 (둔감) | 소형 매장 = 사람이 화면에 크게 잡혀 움직임 과대 측정 보정 |
| 분석 주기 | 6프레임당 1회 | CPU 20~30% 목표 (합산) |
| 키오스크 판정 | 근접(near) 모드 + 몸 폴백 | 카메라를 자판기(키오스크) 위에 설치 — 다가오면 얼굴/몸 크기로 판정, 주문→착석 ID 연결이 핵심 |

## 카메라 설치 (동봉된 「카메라_설치_체크리스트.md」와 함께)

이 매장은 **자판기(키오스크) 위 근접 카메라** 구성입니다:

- 자판기 상단, 주문하는 사람 **얼굴 정면 기준 ±15°**, 화면이 매장 안쪽(좌석 방향)을
  향하게 — 주문하러 오는 사람과 좌석이 한 화면에 들어와야 "주문→착석" ID가 이어집니다.
- 성인이 주문 위치에 섰을 때 **얼굴이 화면 가로의 13% 이상**으로 잡히는 높이/거리
  (대략 1m 이내). 점주 페이지 오버레이로 바로 확인 가능.
- **좌석 6개의 발밑**이 화면에 들어와야 착석 판정이 됩니다 — 1인석 4개가 우선.
- ⚠ 이 매장 특성 주의: **유리 칸막이 반사**(사람으로 오인 — 캘리브레이션으로 마스킹),
  **간접조명 저조도**(카메라 노출을 밝게), 출입문 역광을 정면으로 받는 각도 금지.

## 설치 후 현장에서 해야 할 3가지 (10분)

1. **테이블 존 드래그** — 점주 페이지(`http://localhost:8765`) → 구역 설정에서
   **테이블 존 = 좌석 6개 발밑**으로 드래그. (키오스크는 근접 모드라 존이 필요 없음 —
   카메라 앞 1m 안으로 오면 자동 판정. 판정이 안 되면 "근접 기준" 슬라이더를 낮추세요)
2. **자동 세팅(빈 매장 캘리브레이션)** — 매장이 비는 시간에 [세팅 시작하기] 1시간.
   ⚠ 이 매장은 **유리 칸막이**가 있어 반사 오탐 가능성이 높습니다 — 이 단계가 특히 중요.
3. **화면 확인** — 실시간 오버레이에서 ① 사람 위치가 실제와 맞는지
   ② **주문하러 온 사람이 자리에 앉을 때까지 같은 ID를 유지하는지** (핵심),
   간접조명 환경에서 "카메라 이상(초점/저조도)" 알림이 반복되지 않는지 확인.
   반복되면 카메라 노출 설정을 밝게 하거나 개발자에게 로그 전달.

## 재설치 시

설치형(setup.exe)은 **현장에서 조정한 설정을 보존**합니다 (동봉 프리셋은 첫 설치에만
적용). 압축판(zip)으로 덮어쓸 때는 기존 `store_settings.json`을 미리 백업하세요.
